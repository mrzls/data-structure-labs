# Data Structure Labs (C++)

Лабораторные работы и курсовая по дисциплине «Структуры данных».

## Содержание

| Папка | Описание |
|---|---|
| `lab1` | Реализация динамического массива `Vector<T>` с move-семантикой, итераторами, `reserve`, `shrink_to_fit` |
| `lab2` | Реализация класса `String` с конструкторами копирования/перемещения, операторами `+`, `==`, `<`, методом `uncommon_elements` |
| `lab3` | Односвязный список с move-семантикой, `insert`, `removeKey`, `deleteLess`, `operator!=` |
| `lab4` | Бинарное дерево поиска с итеративным и рекурсивным обходом, удалением узлов, обходом по уровням |
| `lab5` | Хеш-таблица с квадратичным пробированием, подсчётом коллизий, обработкой статусов `EMPTY`/`OCCUPIED`/`DELETED` |
| `coursework` | Курсовая работа: обход в ширину неориентированного графа, поиск кратчайших путей, вычисление диаметра BFS-дерева |


## Структура курсовой работы

Курсовая работа посвящена алгоритмам на графах:

- **BFS (обход в ширину)** — O(n + m)
- **Поиск кратчайших путей** — O(n + m)
- **Вычисление диаметра BFS-дерева** — O(n + m)

Граф представлен **списком смежности** (`Vector<Vector<int>>`). Собственные структуры данных: `Vector<T>` (динамический массив) и `Queue<T>` (очередь на односвязном списке).
